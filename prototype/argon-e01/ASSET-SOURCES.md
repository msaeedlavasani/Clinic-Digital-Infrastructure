# ARGON demo asset notes

- `assets/desire-portrait.webp` — existing generated E01 image; opening portrait and source for the unchanged Laser event.
- `assets/renewal-material.webp` — existing generated image retained as the shader's secondary texture for compatibility. Renewal is not a visitor-facing scene in this Persian-first demo.
- `assets/demo-doctor.jpg` — newly generated illustrative clinician portrait for the Expertise scene. Compressed to JPEG quality 84; shown with an explicit demo/placeholder disclosure. It does not depict a real doctor.
- `assets/demo-clinic-technology.jpg` — newly generated illustrative clinic-room image with a treatment device integrated into the room. Compressed to JPEG quality 84; no brand, product model, or technical claim is represented.
- `assets/argon-df-device.webp` — retained from earlier E01 evidence and not used in this demo journey.
- `assets/fonts/Vazirmatn-variable.woff2` — local variable font from the [Vazirmatn project](https://github.com/rastikerdar/vazirmatn), used for Persian UI and copy. `assets/fonts/OFL.txt` contains its SIL Open Font License.

The existing Argon DF Titanium 2000 product page verified 755, 808, 940 and 1064 nm for earlier E01 research. Those values are not displayed in this demo. No new device specifications or treatment-outcome claims are made.
